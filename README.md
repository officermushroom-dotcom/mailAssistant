# mailAssistant

外国語メールの「読む」と「返す」を1画面で支援する、メール対応特化のAIアシスタントWebアプリです。

ホテルでのアルバイト中、海外のお客様からのメール対応のたびにChatGPTへメールを貼り付け、指示を書き直す作業を繰り返していました。この手間をなくすため、メール対応に必要な処理（要約・翻訳・todo抽出・返信文作成など）をボタン一つで実行できる専用ツールとして開発しました。

![mailAssistantの画面](./screenshot.png)

## 主な機能

### 受信メールを理解する（初期モード：英→日）

| 機能 | 内容 |
| --- | --- |
| 要約する | メールの要点を短くまとめる |
| 翻訳する | 本文を日本語に翻訳する |
| todoを抽出 | 対応が必要な事項を一覧化する |
| 用語を解説 | 専門用語・慣用表現を説明する |
| 感情を分析 | 送信者のトーンや感情を判定する |

### 返信メールを作成する

| 機能 | 内容 |
| --- | --- |
| 日本語で返信文を作成 | 件名＋本文を生成 |
| 英語で返信文を作成 | 件名＋本文を生成 |
| 確認ポイントを提示 | 送信前に見直すべき点を指摘 |
| 別バージョンを生成 | 異なる表現の返信案を生成 |
| 件名を提案 | 返信に適した件名を提案 |
| 口コミに返信 | レビューへの返信文を作成 |

### 共通機能

- **メールの自動分割**：貼り付けたメール全文をLLMが件名・送信元・本文に分割し、新規メールと過去の引用メールを分けて表示
- **シーン設定**：「ホテルのフロント対応」など業務シーンを自由記述で指定でき、ホテル以外の業務にも使える汎用設計（過去の入力履歴から選択可能）
- **カジュアルさ／丁寧さの選択**：プルダウンで文体を調整
- **用語集**：施設名・固有の用語を登録し、AIへの入力に反映
- **NGワード警告**：パスワード等の事前設定した語句が含まれる場合、実行前にモーダルで警告
- **表現の相談**：言い回しについて自由に質問できる
- **履歴とキーワード検索**：サイドバーから過去のメールを検索・再表示

## 技術スタック

| 領域 | 使用技術 |
| --- | --- |
| フロントエンド | React / Vite / TypeScript（UIの初期実装はFigma Makeで生成） |
| バックエンド | Supabase（Edge Functions） |
| LLM | OpenAI API（GPT） |
| パッケージ管理 | pnpm |

## アーキテクチャ

```
[ブラウザ (React)]
      │  メール本文・指示・シーン設定など
      ▼
[Supabase Edge Functions]  ← APIキーはSupabaseのシークレットで管理
      │
      ▼
[OpenAI API]
```

APIキーをフロントエンドに置かず、Edge Functions経由でLLMを呼び出す構成にしています。

### 設計上の工夫

- **2回目以降のリクエストの最適化**：初回実行時にLLMが分割した件名・送信元・本文を保持し、別機能を実行する際はそれを送ることで、毎回全文を再解析しないようにしています。
- **機能ごとに送る情報を変える**：例えば「用語を解説」「感情を分析」では用語集を送らないなど、機能に必要な入力だけを渡しています。
- **段階的な開発**：まずはコピペで完結する構成で現場投入し、ログインや外部連携は後から追加する方針で進めています。
